# Universal Data Visualization Skill

Universal Data Visualization Architect and Code Generation Engine supporting 60 statistical, topological, financial, and geospatial visualization methods.

## Trigger

Invoke this skill whenever the user asks to choose, design, structure data for, or code:

- charts
- dashboards
- diagrams
- maps

across any of these languages/stacks:

- TypeScript / JavaScript
- Python
- R
- C# / .NET
- Go
- Rust
- SQL / DAX

and any of these libraries/tools:

- Apache ECharts
- Chart.js
- D3.js
- Plotly
- Seaborn
- Matplotlib
- ggplot2
- LiveCharts2
- Vega-Lite
- Mermaid.js

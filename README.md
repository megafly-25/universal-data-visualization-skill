## 🌍 Overview (English)

**Universal Data Visualization Architect** is an enterprise-grade AI Agent Skill (`SKILL.md`) that equips any Large Language Model (Claude Code, Cursor, Windsurf, Gemini, ChatGPT, Llama) with a complete mathematical and programmatic decision engine for **60 data visualization methods**.

Instead of generating generic or distorted charts, the AI follows a strict **5-Step Engineering Pipeline**:
1. **Analytical Intent Diagnosis:** Maps business questions to 16 analytical functions.
2. **Cardinal & Structural Validation:** Prevents common visual anti-patterns (e.g., 25-slice pie charts or unnormalized choropleth maps).
3. **Strict Data Contracts:** Enforces clean JSON/SQL schemas per chart type.
4. **Language-Agnostic Code Generation:** Outputs production code for **Apache ECharts, Chart.js, D3.js, Plotly, Seaborn, Matplotlib, ggplot2, LiveCharts2 (.NET), Vega-Lite, and Mermaid.js**.
5. **Mathematical Integrity:** Enforces $r = k\sqrt{\text{value}}$ area scaling, zero-baseline rules, and WCAG AA colorblind-safe palettes (*Viridis*, *Okabe-Ito*).

```bash

```

### 2. Claude Code / Claude Desktop
Copy `SKILL.md` into your project's `.claude/skills/universal-dataviz-architect/SKILL.md` directory.

### 3. Cursor IDE / Windsurf / VS Code Copilot
Copy the contents of `SKILL.md` into your `.cursorrules` or `.github/copilot-instructions.md` file.
